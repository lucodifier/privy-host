Cada um vê só o que é seu

Permissões por sistema, aplicadas no servidor. O root é quem cadastra sistemas e usuários.

👑 Root

  • Cadastra, edita e exclui sistemas
  • Cadastra, desativa e exclui usuários
  • Vincula cada usuário aos seus sistemas
  • Enxerga todos os sistemas e acessos

🧑‍💻 Usuário do sistema

  • Vê e edita os acessos só dos sistemas vinculados a ele
  • Não enxerga nem altera outros sistemas
  • Não cadastra sistemas nem usuários
  • Troca a própria senha no primeiro login

Segurança sem mistério

O que protege seus dados, e o que é responsabilidade sua.

✅ O que o Priv Host faz

  • Cifra cada registro com AES-256-GCM (IV aleatório + tag)
  • Mantém a chave fora do banco e fora do Git
  • Login com senhas scrypt, sessão HttpOnly e bloqueio por tentativas
  • Valida a permissão de cada sistema no servidor
  • Rejeita mutações com Origin diferente do host
  • Responde com Cache-Control: no-store
  • Publica só em 127.0.0.1 por padrão

⚠️ O que fica com você

  • Prefira rede privada ou proxy HTTPS; evite expor na internet
  • Faça backup do banco e da chave
  • Sem a chave, os registros não são recuperáveis
  • Não exponha na internet

Pronto para começar?

Docker é o caminho recomendado. Para desenvolver, use Node.js 24+.

Suba com Docker

git clone https://github.com/lucodifier/privy-host.git
cd privy-host
docker compose up -d --build

Abra no navegador

http://localhost:3000           # dashboard
http://localhost:3000/systems   # cadastro

Ou rode em modo dev

cp .env.example .env   # defina PRIV_HOST_ENCRYPTION_KEY
npm install
npm run dev
⚠️ Primeiro acesso: entre como root (senha em PRIV_HOST_ROOT_PASSWORD ou nos logs do container). Prefira rede privada ou HTTPS.
